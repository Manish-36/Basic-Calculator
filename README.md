# Basic Calculator

A sleek, responsive web-based calculator built with vanilla HTML, CSS, and JavaScript[cite: 3, 4, 5]. It supports standard arithmetic operations, decimal inputs, single-character backspace deletion, and full display clearing[cite: 3, 4].

## Features

* **Standard Arithmetic:** Perform addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
* **Decimal Support:** Includes decimal point (`.`) functionality for floating-point calculations[cite: 3].
* **Backspace & Clear Controls:** Delete the last entered character (`<=`) or reset the entire display (`C`)[cite: 3, 4].
* **Modern Grid UI:** Styled with CSS Grid, color-coded action buttons, hover transitions, and a read-only display screen[cite: 3, 5].
